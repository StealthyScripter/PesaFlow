# PesaFlow brand notes

Audience: SACCO administrators and members.

Working accent: `#7c3aed`; background: `#101827`; text: `#ffffff`. These are campaign draft colors, not a replacement for application styling. Use existing copied logos where supplied. `concept-mark.svg` is an unapproved fallback initial mark; do not present it as established branding.

Use plain, specific language and feature descriptions. Avoid unsupported performance, savings, security or outcome claims. Artwork uses system sans-serif; check font substitution on export.
