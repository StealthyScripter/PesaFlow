# Play Store artwork drafts

`feature-graphic.svg` is a 1024×500 editable draft. `icon-concept.svg` is a 512×512 fallback concept, not an approved store icon. Prefer the established app icon if one is supplied under logos. Export artwork to PNG in a design editor and inspect the final images before upload. These SVGs are source artwork, not upload files.

Store listing text lives in `../../copy/messaging.md`; screenshots live in `../../screenshots/mobile/`. Android distribution is not assumed for this project. Verify current Play Console requirements and eligibility when preparing an actual release. No listing or store availability is implied.
